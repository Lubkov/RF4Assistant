# Мастер «Новое место ловли»

Глобальная кнопка `+` подключена в `templates/base.html`; модальное окно и шесть шагов находятся в `templates/includes/fishing_spot_wizard.html`. Стили и JS: `static/css/fishing-spot-wizard.css`, `static/js/fishing-spot-wizard.js`. Для карты динамически загружается Leaflet (требуется доступ к CDN).

- `GET /fishing-spots/options/` — активные водоёмы, параметры игровых карт и связанные с ними активные рыбы. Устанавливает CSRF cookie.
- `POST /fishing-spots/create/` — multipart-form-data с категориями, водоёмом, координатами, параметрами, рыбами и скриншотами. Проверяет входные данные; сохраняет точку, связи и изображения в WebP.
- Лимиты: 1–2 категории, 1–10 видов рыб, 2–10 PNG/JPEG/WebP до 10 МиБ каждое. Обложка — скриншот с `position=1`.
- Клипса, глубина в сантиметрах, скорость проводки 1–50 — необязательные целые числа.
- Наличие карты с калиброванными игровыми координатами обязательно для ввода точки.
- Все точки общие; авторизация, редактирование, удаление и отдельная страница просмотра пока не реализованы.

Для установки обновления: `python manage.py migrate`. Проверка: `python manage.py test fishing_spots`. Доступность Leaflet CDN необходима для карты.
