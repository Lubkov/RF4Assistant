# RF4 Assistant v0.1 — этап 4: главная страница

Локальный Django-сайт с каталогом водоёмов. На главной выводятся **активные** водоёмы из SQLite (по уровню доступа, затем по ID). Карточки не ведут на отдельные страницы; пункт «Карты» в меню прокручивает страницу к соответствующей карточке.

## Требования

- Python 3.10+ (рекомендуется Python 3.12 или 3.13)
- Django 5.2, Pillow (см. `requirements.txt`)
- Доступ к CDN jsDelivr для Bootstrap 5.3.3: при работе без интернета Bootstrap-стили/меню не загрузятся. Локальный CSS, JS и изображения останутся доступны.

## Запуск в Windows PowerShell

```powershell
cd C:\path\to\rf4-assistant
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe manage.py runserver
```

Откройте http://127.0.0.1:8000/ . Django Admin: http://127.0.0.1:8000/admin/ . Администратора создают командой `manage.py createsuperuser`.

Если виртуальное окружение уже существует, **не нужно создавать его повторно**; распакуйте файлы поверх проекта, сохранив `db.sqlite3`, `.venv` и загруженные `media/`.

## Этапы

1. Проект Django: приложения `core`, `waterbodies`, `fish`, шаблоны, настройки SQLite/static/media.
2. Модели `Waterbody`, `Fish`, `WaterbodyFish`, миграции с 18 водоёмами и 251 видом рыб. Значение `9999999` у двух супертрофеев заменено на `NULL`; связи изначально пустые.
3. Django Admin: редактирование справочников, загрузка и предпросмотр изображений, встроенные связи `WaterbodyFish` с автодополнением по названию рыбы.
4. Главная: адаптивная сетка карточек, локальная SVG-заглушка, навигация «Карты», подвал, тёмная тема по умолчанию и переключение на светлую с сохранением в `localStorage`.

## Изображения

В разделе **Водоёмы** Django Admin загрузите подготовленное изображение (рекомендуем WebP, 1280×720, 16:9). Файлы сохраняются в `media/waterbodies/`, в базе хранится относительный путь. Изображение в карточке автоматически подгоняется под 16:9 через `object-fit: cover`. Если файла нет, отображается `static/images/waterbody-placeholder.svg`.

## Развёртывание

Этот проект настроен для локальной разработки. Bootstrap подключается с CDN. `SECRET_KEY` содержит только локальное демонстрационное значение, а `DEBUG=1` по умолчанию. Для публичного сайта задайте переменные окружения `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, `DJANGO_ALLOWED_HOSTS` и настройте отдачу статических файлов и загруженных изображений отдельным сервером/хранилищем. Не публикуйте `db.sqlite3`, `.venv`, `media/` и секреты в Git.


## Этап 5 — справочник видов рыб (`/fish/`)

Добавлена общедоступная страница `/fish/`, пункт «Рыбы» в верхнем меню, поиск по названию, фильтрация по редкости и сортировка.
В таблице показаны название, вес трофея, вес редкого трофея и редкость; веса в базе хранятся в граммах и форматируются в браузере (до 1000 г — граммы, от 1000 г — килограммы).
Рисунки редкости в `static/images/rarity-{1,2,3}.svg` повторяют согласованную палитру и геометрию.
Для 251 строки используется клиентская фильтрация без дополнительных серверных запросов.
Новые миграции не нужны; существующие справочники и данные не менялись.

После обновления файлов запустите `python manage.py check`, `python manage.py test` и `python manage.py runserver`.

## Этап 6 — уточнение навигации и иконок редкости

Меню «Справочник» (в единственном числе) содержит пункт «Виды рыб» и рассчитано на будущие справочники.
Заголовок страницы `/fish/`: «Справочник видов рыб в Russian Fishing 4».
Значки `rarity-2.svg` и `rarity-3.svg` теперь однотонные, без белых внутренних элементов; внешний силуэт, размеры и исходные цвета сохранены.
Изменения не требуют миграций.
